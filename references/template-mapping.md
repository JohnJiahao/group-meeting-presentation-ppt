# 套用用户已有 PPT 模板生成汇报稿（pptx）

目标：把 5 模块的 Markdown 稿，变成**和用户上一次汇报同一套版式**的 pptx。
不要重做设计，只做「复制页 → 改字 → 插图 → 排序」。

---

## 1. 先把素材备齐

```bash
# 图/表按图注自动裁切（400dpi，裁完务必肉眼看一遍）
python scripts/pdf_figs.py paper.pdf -o figs \
    fig1="Fig. 1" fig2="Figure 2" fig3="Fig. 3" \
    fig5="Fig. 5" fig6="Fig. 6" \
    tab1="Table 1" tab2="Table 2" tab5="Table 5"
```

要点：

* **不要用 `page.get_images()` 直接抽内嵌位图**——论文里图上的文字（模块名、坐标轴、图例）
  常是矢量文本，抽出来是“空框图”。一律用 `get_pixmap(clip=...)` 按区域渲染。
* 表注在表上方、图注在图下方，`pdf_figs.py` 已按此处理；跨栏大表（Table 3 这种 6 列）
  的 x 范围取整页，别按单栏裁。
* 裁掉 `Table 2` / `Fig. 3` 这类英文图注（幻灯片上写中文图注），否则会出现半截英文标题。

## 2. 盘点模板

```bash
python scripts/inspect_template.py 模板.pptx -o tpl.txt
```

找出四类可复用的“原型页”：

| 原型 | 典型特征 | 复用方式 |
|---|---|---|
| 封面 | 版式「标题幻灯片」，大标题+副标题+汇报人+日期 | 直接改字 |
| 提纲 | 独立一页，四个条目 | 原样保留 |
| 文字页 | 页眉色块 + 左侧「一/二/三」标 + 标题占位符 + 正文框 | 改标题与正文 |
| 图片页 | 小标题两行 + 正文框（黄底标签）+ 左下图片 + 右下中文图注 | 换图、改图注 |

同时记住：**形状名**（如 `文本框 2` 是正文、`文本框 4` 是页眉小标题、`图片 7` 是旧图）、
**坐标**（L/T/W/H，单位英寸）——照抄即可保持版式不变。

## 3. 写一个 build 脚本

在临时目录写 `build_deck.py`（不要污染用户文件夹），骨架：

```python
import sys
sys.path.insert(0, r"<skill>\scripts")
from deckkit import Deck

d = Deck(TEMPLATE, OUT)
S = list(d.slides)

# 1) 复制需要的原型页
cover, outline, text_pg, pic_pg, concl = S[0], S[1], S[2], S[8], S[16]
abs_new = d.dup(text_pg)
cmp_new = d.dup(pic_pg)

# 2) 删掉不用的原型页（先取 slide_id，再删）
for sl in (S[9], S[10]):
    d.delete(sl)

# 3) 重排为最终顺序
d.reorder([cover, outline, abs_new, text_pg, ..., concl])

# 4) 改字：定位 -> 清空 -> 分段写
tf = d.setup(cover, "文本框 4", 0.68, 3.9, 12.2, 0.6)
d.para(tf, [("中文译名", {"bold": True})], first=True, size=23, color=d.BLUE)

# 5) 图片页：删旧图、插新图、改图注
d.drop(pic_pg, "图片 7")
d.pic(pic_pg, "figs/tab2.png", 0.45, 4.4, w=4.3)
tf = d.setup(pic_pg, "文本框 5", 5.0, 4.45, 7.95, 2.55)
d.para(tf, [("Table 2：", {"bold": True}), ("中文图注……", {})], first=True, size=13)

d.save()
```

## 4. 必踩的坑（都在 deckkit 里处理了，但要知道原因）

1. **复制页后图片会丢**：`deepcopy` 只搬 XML，`r:embed` 指向原页的关系；复制页里的旧图片
   必须 `drop` 掉，再用 `add_picture` 重新插入（新关系才会建对）。
2. **`slide.slide_id` 在清空 `sldIdLst` 后会报错**：`reorder` 先取 id 再清空，顺序不能反。
3. **删除页只删 `sldIdLst` 不够**：还要 `part.drop_rel(rId)`，否则文件里残留孤立 slide。
4. **中文段落不要用 JUSTIFY**：两端对齐会把 `，`、`。` 顶到下一行行首，中英文之间被拉出大空隙。
   一律 `align=LEFT`，并给 run 加 `lang="zh-CN"`（deckkit 已加）——这是中文换行/避头尾生效的关键。
5. **占位符**：复制出来的页沿用原版式，不要另外 `add_slide` 造页，否则页眉色块和「一/二/三」标会丢。
6. **字号与溢出**：正文 15–18pt，图片页说明 12–13pt。创新点是 3 段白话解释（各 2–3 句），
   右侧放图时正文框只给 6.3–6.5in 宽、16–17pt；放不下就拆页，别缩字号、别把三段并成一段。
   实验页的“最终说明了什么”要带数值与读图结论（点名最高/最低、差多少、错分在哪两类），
   正文会到 5–6 行：正文 15pt、宽 12.0–12.2in，表格/图放下面（宽 4.3–9.0in、高 ≤3.0in），
   右下图注 12–13pt。一个实验装不下就拆成“文字页 + 图页”，或 Table/Figure 分页。
   写完一定导出 PNG 逐页看，别凭感觉。

## 5. 自检（导出 PNG 逐页看）

```powershell
# PowerPoint COM 导出，最接近真实放映效果
$pp = New-Object -ComObject PowerPoint.Application
$pres = $pp.Presentations.Open($src, $true, $false, $false)
for ($i=1; $i -le $pres.Slides.Count; $i++) {
  $pres.Slides.Item($i).Export("$out\s$i.png", "PNG", 1600, 900)
}
$pres.Close(); $pp.Quit()
```

逐页确认：

* [ ] 图/表不压字、不超出页面，表格文字可读（宽表 ≥ 8in）
* [ ] 没有残留上一版文字（旧图注、旧数据集名、旧汇报人）
* [ ] 中文断行正常，行首没有 `，。、`
* [ ] 每页只有一个主题，与 5 模块的编号对得上
* [ ] 英文原文与论文逐字一致，图号真实存在

## 6. 页数控制

参考配比（14 页左右最稳）：

```
封面 1 | 提纲 1 | 摘要 1（中文或英文，一页）| 问题+方法 1
创新点：整体框架全流程 1（第一页，编号“一”）+ 创新点 3–4（编号二~五）| 数据集 1
对比实验 2–3（含混淆矩阵/t-SNE 可视化 1）| 消融 1 | 结论 1
```

封面上的**汇报人、汇报日期必须用用户提供的值**：不要沿用模板 deck 里上一次的名字，
也不要用系统当天日期。摘要、结论各按用户选的语言排页（中文/英文，共 4 种组合），一页只放一种语言。

**整体框架全流程页的排法**（模板里没有现成页时，复制一个“文字页”改）：

* **位置：创新点部分的第一页**——先讲全貌，再逐条拆创新；编号「一」，四条创新点改为二/三/四/五。
* 左：`文本框 4` 收窄到 4.5–4.7in、字号 13pt，写 6–7 步（用 ①②③ 编号，加粗步骤名）；
* 右：Fig.1 原图放到 7.5–7.8in 宽（高 ≈4.2in），整图不裁，保证能指着讲；
* 图下 10.5–11pt 小字注明“左：… 中：… 右：…”，帮听众对位；
* 最后一步下面加一行“可替换点：信号/主干/任务头”，一句话交代通用性。
* 这一页只讲流程，不重复后面创新点的“老问题/创新做法”；创新点页若也用到 Fig.1，改用局部裁切。

创新点页若文字短、右侧空，就把对应的**方法图局部放大**放右侧（例如门控融合只截
Gated Fusion 那一小块），比留白好看，也比整图缩小更清楚。注意同一张 Fig.1 不要在两页
原样重复：创新点页用局部（如“模态融合+主干”），全流程页用整图。

注意：创新点的「老问题／创新做法／解决了什么问题」是**详细白话解释**（各 2–3 句、40–80 字），
不是四五个关键词。排版上按下面二选一：

* 三段共约 9–11 行 → 正文框 6.3–6.5in 宽、16–17pt，右侧放 5.3–5.6in 宽的图；
* 超过 12 行 → 拆成两页（老问题+创新做法 / 解决了什么+配图），或把图挪到下一页单独一页。

判断能否放下的粗暴公式：段宽(in) ≈ 字号(pt) × 0.017 × 每行汉字数；行高 ≈ 字号 × 1.3 / 72 英寸。

## 7. 换别人的模板（形状名完全不同的情况）

```bash
python scripts/adapt_template.py 别人模板.pptx -o tpl_map.json -m tpl_map.md
```

* 角色按「占位符 idx 0 / 名字含标题 / 顶部大字（字号×宽度）/ 面积最大 / 下半页小字 / 图片类型」推断，
  输出 `title / subtitle / body / caption / picture / page_no / header`。
* build 脚本里先用 JSON 查名字，再交给 `deckkit.setup(slide, name, …)`；不要写死 `文本框 2`。
* 判错了改 JSON 的 role 就行，脚本不用动。
* 常见例外：①封面没有标题占位符、顶部有条“页眉红字”——用 `subtitle` 承接；②提纲页全是装饰矩形，
  把真正的“提纲”大字改回 `title`；③卡片式版式（多列小卡片）没有单一 `body`，把每张卡片的框当独立段落处理。
* 版式差异太大（瀑布流、图文混排）时，退回“复制一页空白页 + 自己加文本框”，字号/字体从 JSON 里的
  `font` 取值、颜色取模板主题色，风格仍然接近原 deck。
